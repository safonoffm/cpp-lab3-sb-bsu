# cpp-lab3-sb-bsu

C++ programs from Practical Work 3 of the course Principles of Algorithmization and Programming (SB BSU).

`3a-t4.cpp` is task 4 from Practical Work 3B: it asks how many integers you want to add, reads them one by one with a `do while` loop and prints the sum.

Branches: `check-for-zero` handles k = 0 (task 4.2), and `integer-check` warns about input that is not an integer (task 4.3).
